# 跨平台选择与官方歌曲页（2026-10-24）

选择歌曲会按同一作品关联两个平台，切换平台不再清空歌名。若另一平台没有匹配条目，仍保留歌名并明确提示未收录；不会猜测外链。取消选择同时清除两个平台的选择，平台各自的搜索、专辑和排序保持原状。刷新继续恢复当前选择与视图。

网易云选歌后提供明显的「在网易云音乐打开」按钮，打开对应已核对歌曲ID的官方页面。自动浏览器已触发新页面，但页面内容观察被站点安全策略拦截，未核验该站内实际播放。

Apple 优先使用官方嵌入，移除页面额外添加的 iframe sandbox，保留 autoplay/encrypted-media 等官方播放所需权限。新增常驻官方歌曲页按钮，链接与播放地区同步。新增「中国大陆（尝试）」地区：该区收录/版权未核验，不能保证同一ID可用。地区选择全局记忆。仍是90秒表示平台当前提供试听，不能据此判断用户未登录；需确认有效Apple Music订阅、账号地区和浏览器内授权。没有用户订阅账号，因此未验证付费完整播放。本站不读取或伪造嵌入播放器订阅状态，也没有把试听拼接成完整版。

# 每首只保留一个版本（2026-10-24）

页面现在 Apple Music 135首、网易云192首。每个平台按作品归一，原版录音室优先于重录、现场、混音与伴奏；精选集和单曲中重复发行同一作品不重复显示。只有现场版本的作品保留一个可获取版本，多曲串烧/联唱不列入单曲列表。简繁、常见中英标题别名也做归一，保留不同歌曲如「睡公主」与「依然睡公主」。原始平台数据仍保留在 data/catalog.json，构建时由 tools/dedupe.py 选出代表版本。

旧的所选歌曲ID会迁移到新列表代表版本，搜索、排序与浏览器记忆保持可用。专辑筛选只列出最终保留版本所在专辑。最多播放仍为第三方 Spotify 同名版本参考，未提供数据时不补造。

# G.E.M. 音乐资料库

已直接修改上传项目的 `index.html`，使用白色、浅灰和系统控件，移除了原有宣传卡片及外部搜索跳转。

## 打开与使用

- `index.html` 是完整独立页面，已内嵌样式、脚本和歌曲目录；封面按需联网加载。电脑用浏览器打开即可；不需要安装依赖或运行后端。
- 手机上请通过 Safari 打开部署后的网页。iOS「文件」中的 HTML 预览不等于 Safari 网页，可能不执行脚本或载入第三方播放器。
- 选择平台 → 输入关键词实时筛选 → 点击歌曲 → Apple Music 在列表上方显示官方播放器；网易云显示当前播放限制。
- 使用「全部专辑」筛选发行版本，支持排序；筛选不会移除已选择的播放器。
- 播放需要联网。浏览和搜索无需实时调用平台接口。

## 目录

快照日期：2026-10-24（中国标准时间）。Apple Music 282 条，网易云音乐 419 条，均按真实曲目 ID 去重；不同发行的同名曲目和不同版本予以保留，两个平台数量不能相加视为独立歌曲总数。

Apple：通过歌手 ID `425208570` 查询其发行目录，再按专辑 ID 获取歌曲。曲目只保留该歌手 ID，或合作演唱者字段明确含「邓紫棋 / 鄧紫棋」的记录。中国大陆 iTunes 接口本次只返回专辑，未返回歌曲，实际单曲取自香港和台湾商店。播放器地区使用该曲目的已获取地区。

网易云：通过官方歌手 ID `7763` 的全部歌曲分页目录获取，逐首验证演唱者 ID。平台 total=420，本次实际返回并通过核验的曲目为419条，不补造缺失记录。其中3条没有提供专辑信息，已显示「专辑信息未提供」。目录包含合作、演唱会及综艺演唱版本，不包含其他歌手单独翻唱的歌曲。

目录是可获取范围内的快照，无法承诺覆盖所有国家、下架作品及后续发行；平台可随时变更版权和收录信息。

## 播放限制

- Apple Music 优先使用 `embed.music.apple.com` 的官方单曲播放器。未登录通常仅能试听；完整播放需要订阅、地区版权和浏览器支持。试听长度由平台决定，本次《光年之外》的官方嵌入播放器显示90秒试听，并实际推进至37秒。
- iPhone Safari 通常需要再次点击嵌入播放器中的播放键，不伪造自动播放、暂停或进度。
- Apple 播放器无法载入时，帮助区可改用平台返回的官方试听片段和浏览器原生音频控件；不是完整音频下载。
- 网易云使用官方 HTTPS `outchain/player?type=2` 播放器，没有使用第三方破解接口。实测可以载入《光年之外》的正确曲名和官方控件，但播放未能推进，停留00:00。独立页面复核后发现官方脚本自身出现跨域错误。最终版本不自动嵌入该不可用控件，选歌后明确显示「暂不可在本页播放」，提供切换 Apple Music 及手动打开平台链接；网易云列表使用信息图标，不伪装成可播放。
- 列表点击不包含外部导航。仅明确标明的「手动打开平台歌曲页 / 网易云歌曲页」链接会在新页面打开官方曲目。官方播放器自身也可能提供登录、订阅和平台按钮。
- 第三方播放器受到跨域隔离，父页面不能可靠读取播放状态，因此页面仅显示「已选择」，不冒充「正在播放」。

## 源码与维护

- `index.html`：可直接使用的完整网站。
- `tools/page.html`：页面源码模板。
- `data/catalog.json`：核验后的歌曲数据及来源说明。
- `data/covers.json`：已缓存的官方小封面。
- `tools/fetch_catalog.py`：Python 3 标准库目录更新脚本；无需账号与密钥，不下载音频。
- `tools/fetch_covers.py`：官方封面小图缓存。
- `tools/build.py`：将数据与模板生成为单文件 HTML。
- `TEST-REPORT.md`：实际验证记录。

可选维护命令，在项目目录中运行：

```sh
python3 tools/fetch_catalog.py
python3 tools/fetch_covers.py
python3 tools/build.py
```

不需要执行这些命令即可使用现有页面。更新脚本读取平台公开目录，若平台接口收紧或返回不完整目录，需要按当时实际情况调整；未通过最小完整性检查时会拒绝覆盖旧目录。
